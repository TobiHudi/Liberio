# Liberio

A simple shelf sorting and upgrading game.
**Project to get me into a Software Engineering Apprenticeship!**


## About the Code:

This project only includes my own approach to solutions for problems I've encountered.
I tried to approach all the problems as Signal-, Event-based as possible, so no unnecessary heavy logic runs every frame.


## About my Mindset for this Project:

As a self-thaught developer I do not guarantee that this code is the most elegant, performant, efficient and scalable that it could be.
Currently I'm only an enthusiast and no professional in coding. This will change in the future, once I hopefully receive an Apprenticeship and learn coding the most elegant, performant, efficient and scalable way possible.
